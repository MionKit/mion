---
title: Column Mapping
description: How types are mapped to database columns when using mion Drizzle ORM package.

---

The `@mionjs/drizzle` package automatically maps TypeScript types to appropriate Drizzle ORM column definitions. This mapping is database-aware, using native column types where available (e.g., PostgreSQL's `uuid()` and `inet()`) and falling back to compatible alternatives for databases with fewer native types (e.g., SQLite uses `text()` for most string formats).

Type formats from `@ts-runtypes/core/formats` provide additional semantic information that enables more precise column mapping. For example, `Integer` maps to an integer column rather than a floating-point column, and `Email` uses the appropriate varchar length for email addresses.

## Primitive Types

| TypeScript Type | PostgreSQL | MySQL | SQLite |
|-----------------|------------|-------|--------|
| `string` | `varchar(255)` | `varchar(255)` | `text()` |
| `number` | `doublePrecision()` | `double()` | `real()` |
| `boolean` | `boolean()` | `boolean()` | `integer({mode: 'boolean'})` |
| `bigint` | `bigint({mode: 'bigint'})` | `bigint({mode: 'bigint'})` | `blob({mode: 'bigint'})` |
| `Date` | `timestamp()` | `timestamp()` | `integer({mode: 'timestamp'})` |

## String Format Types

| Format Type | PostgreSQL | MySQL | SQLite |
|-------------|------------|-------|--------|
| `UUIDv4` / `UUIDv7` | `uuid()` | `varchar(36)` | `text()` |
| `Email` | `varchar(254)` | `varchar(254)` | `text()` |
| `StrURL` | `varchar(2048)` | `varchar(2048)` | `text()` |
| `Domain` | `varchar(253)` | `varchar(253)` | `text()` |
| `IP` / `IPv4` / `IPv6` | `inet()` | `varchar(45)` | `text()` |
| `StringDateTime` | `timestamp()` | `datetime()` | `text()` |
| `StringDate` | `date()` | `date()` | `text()` |
| `StringTime` | `time()` | `time()` | `text()` |
| `String` (with maxLength) | `varchar(maxLength * buffer)` | `varchar(maxLength * buffer)` | `text()` |

Well-known formats like `Email`, `StrURL`, and `Domain` use their standard maximum lengths without any buffer applied.

## Number Format Types

All number formats with the `integer: true` parameter map to integer columns, while formats with `float: true` or no integer constraint map to floating-point columns.

| Format Type | Description | PostgreSQL | MySQL | SQLite |
|-------------|-------------|------------|-------|--------|
| `Integer` | Generic integer | `integer()` | `int()` | `integer()` |
| `Float` | Generic float | `doublePrecision()` | `double()` | `real()` |
| `Positive` | Number >= 0 | `doublePrecision()` | `double()` | `real()` |
| `Negative` | Number <= 0 | `doublePrecision()` | `double()` | `real()` |
| `PositiveInt` | Integer >= 0 | `integer()` | `int()` | `integer()` |
| `NegativeInt` | Integer <= 0 | `integer()` | `int()` | `integer()` |
| `Int8` | 8-bit signed (-128 to 127) | `integer()` | `int()` | `integer()` |
| `Int16` | 16-bit signed (-32768 to 32767) | `integer()` | `int()` | `integer()` |
| `Int32` | 32-bit signed | `integer()` | `int()` | `integer()` |
| `UInt8` | 8-bit unsigned (0 to 255) | `integer()` | `int()` | `integer()` |
| `UInt16` | 16-bit unsigned (0 to 65535) | `integer()` | `int()` | `integer()` |
| `UInt32` | 32-bit unsigned (0 to 4294967295) | `integer()` | `int()` | `integer()` |

::callout{type="info"}
While the database column type is the same for all integer formats, the type constraints (min/max values) are still validated at runtime by mion's type system.
::

## BigInt Format Types

| Format Type | PostgreSQL | MySQL | SQLite |
|-------------|------------|-------|--------|
| `BigInt` | `bigint({mode: 'bigint'})` | `bigint({mode: 'bigint'})` | `blob({mode: 'bigint'})` |

## Date and Temporal Format Types

Temporal values are stored as ISO strings. Database drivers cannot return Temporal instances, so these columns use Drizzle's string modes and your code parses the string back when needed. A ZonedDateTime keeps its time zone name only when stored as text.

| Format Type | PostgreSQL | MySQL | SQLite |
|-------------|------------|-------|--------|
| `Date` (native) | `timestamp()` | `timestamp()` | `integer({mode: 'timestamp'})` |
| `Instant` | `timestamp({withTimezone: true, mode: 'string'})` | `timestamp({mode: 'string'})` | `text()` |
| `ZonedDateTime` | `text()` | `text()` | `text()` |
| `PlainDate` | `date({mode: 'string'})` | `date({mode: 'string'})` | `text()` |
| `PlainTime` | `time()` | `time()` | `text()` |
| `PlainDateTime` | `timestamp({mode: 'string'})` | `datetime({mode: 'string'})` | `text()` |
| `PlainYearMonth` | `varchar(7)` | `varchar(7)` | `text()` |

## Literal Unions

A property typed as a union of string values becomes an enum column, so the database also knows the allowed values:

```ts
interface Post {
    id: string;
    status: 'draft' | 'published';
}
```

| Database | Column |
|----------|--------|
| PostgreSQL | `text({enum: ['draft', 'published']})` |
| MySQL | `mysqlEnum(['draft', 'published'])` |
| SQLite | `text({enum: ['draft', 'published']})` |

::note
PostgreSQL native enums (`pgEnum`) are named database objects that migrations must know about, so they are never generated automatically. If you want one, define it yourself and pass the column in the tableConfig override.
::

Unions that mix strings with other types fall back to a plain string column.

## Complex Types

| TypeScript Type | PostgreSQL | MySQL | SQLite |
|-----------------|------------|-------|--------|
| `T[]` (array) | `jsonb()` | `json()` | `text({mode: 'json'})` |
| `{...}` (object) | `jsonb()` | `json()` | `text({mode: 'json'})` |
| `FormattedArray` | `jsonb()` | `json()` | `text({mode: 'json'})` |
| `FormattedObject` | `jsonb()` | `json()` | `text({mode: 'json'})` |
