## Installation

```bash
npm install @mionjs/platform-uws @mionjs/router
```

The native uWebSockets.js binaries install automatically. They ship as per platform packages that npm picks for your machine, so no compiler and no extra steps are needed.

::caution
uWebSockets.js publishes prebuilt binaries only for even Node.js versions (currently 22, 24 and 26) on Linux (glibc), macOS and Windows x64. On other Node versions or on Alpine Linux the server will not start; use the Node.js platform there instead.
::
