These benchmarks are based on the [fastify benchmarks](https://github.com/fastify/benchmarks){target="_blank"} repo! in fact our goal is to perform similar to fastify as we considered it the industry standard in terms of performance.

mion is focused on being lightweight and fast so it can be run in serverless environments. The numbers below are generated on every docs deploy, straight from the code in this repository, so they never drift from the released version.

::tip
**Hello World** benchmark involves mostly routing as there is no validation and is about as fast as each framework can get.
::

## What is tested?

This is a simple hello world scenario, is a good indicator of the router performance and theoretical upper limit of each framework.
