Each chart is the geometric mean over every case in that group. A library that does not support a case scores it at the slowest result among the libraries that do, so supporting more cases never lowers a score. The link on each chart opens those cases on GitHub. The last chart, Strict, rejects any value with an extra key instead of ignoring it.
