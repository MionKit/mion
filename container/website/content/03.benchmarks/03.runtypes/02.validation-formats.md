Each chart is the geometric mean over the cases in that group that every library supports. The link on each chart opens those cases on GitHub.

::note
zod is not on this page. It has no fast is-valid check: the only way to ask zod whether a value matches is to have it build the full error report, so its number belongs on the [validation errors](/benchmarks/runtypes/getvalidationerrors-formats) page, where every library is measured on that same work.
::
