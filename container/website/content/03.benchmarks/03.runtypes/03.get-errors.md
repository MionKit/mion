Each chart is the geometric mean of every case in its group. A library that does not support a case gets the slowest result of the libraries that do. Supporting more cases never lowers a score.

The link on each chart opens those cases on GitHub. The last chart, Strict, rejects any value with an extra key instead of ignoring it.
