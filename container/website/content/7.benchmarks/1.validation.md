The JSON Schema section at the end covers constraints only a schema document can state, like closing an object to a fixed set of keys, requiring array items to be unique, or making one property depend on another. RunTypes reads the document itself, and every other library states the same constraint in its own dialect. A library whose dialect cannot express one reads n-a.
