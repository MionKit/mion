Every other page here asks how fast each library validates a shape, with each library describing that shape in its own dialect. This page asks the narrower question: given the same JSON Schema document, how fast is each library that can consume it directly?

Only two columns can answer. RunTypes reads the document at build time and generates a validator from the type it denotes. AJV compiles the very same document at run time. The others have no JSON Schema input door: zod and typia can emit a schema but not build a validator from one, and TypeBox needs a separate code generation step rather than a runtime call.

The type cost side of the same comparison lives on the [compile time](/benchmarks/compiletime) page, where `ts-runtypes (jsonSchema)` and `json-schema-to-ts` both recover a TypeScript type from these documents. AJV has no column there at all, which is the honest shape of the trade: it validates against the document but leaves you without a type.

See [the JSON Schema guide](/guide/json-schema) for what the input accepts.
