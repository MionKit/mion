## Converting Files Between Types and Builders

RunTypes accepts two ways to write a shape: a plain TypeScript type and the type builders. The convert command rewrites your files from one form to the other, in place.

```bash
# one file, or several
npx mion convert --to builders src/models.ts src/api.ts

# or a whole folder (every .ts and .tsx inside it)
npx mion convert --to type src/models/
```

The targets are `type` and `builders`. Declarations already in the target form are left byte-for-byte unchanged, so running the command twice is safe.

## Shapes That Convert

Everything RunTypes reflects: primitives and literals, string and number formats, arrays, tuples, objects (optional, readonly and quoted keys included), records, unions, enums, classes, Date, Map, Set, Promise, RegExp, Temporal types, functions, template literals, branded types, and recursive types.

In builder form, labeled tuples and named function parameters use `RT.slot`, an index signature beside named properties becomes an intersection, and recursive shapes come out as `RT.circular` with `RT.self()`.

## Recursive Types

Some recursive types have no value spelling for the loop: a type that also needs the `getRunType` escape (usually a method member), and a type that loops back through one of its own tuple slots, like `type Pair = [number, Pair]`. The converter keeps the type declaration as written and adds a handle const beside it.

```ts
export type TreeNode = {label(): string; kids: TreeNode[]};
export const treeNodeRT = getRunType<TreeNode>();
```

That pair is the builder form. Running the conversion again leaves it alone, and converting back to the type form removes the const.

## References Between Files

A type that names another converted type keeps the name in every form. Convert the files together and the imports are updated for you.

```bash
npx mion convert --to builders src/user.ts src/order.ts
```

## Shapes That Do Not Convert

Most shapes that the builder form has no word for still convert, through an escape that carries the type itself, `getRunType<T>()`. That covers functions, template literals, bigint literals and more.

The shapes below cannot be written inside the escape either. The converter reports the shape, leaves that declaration exactly as you wrote it, converts the rest of the file, and exits with a non-zero code.

| Shape | Why |
| ----- | --- |
| A cycle that never passes through a named type | The self reference has nothing to point at. Give the inner type a name and it converts. |
| A symbol-keyed property | The escape can only carry a type it can write down, and a symbol name is not one. |
| A unique symbol literal type (`typeof sym`) | No builder can spell a symbol value. |
| A property tagged `@nonEnumerable` | The tag shapes the wire format but has no builder spelling, so dropping it would change the type's identity. |
| A recursive type reaching a call site through a mapped type such as `DataOnly<T>` | The mapping hands the call an unnamed copy of the loop, so there is no name to close it on. Pass the named type itself and it converts. |
| A recursive tuple reaching a call site through a mapped type | Same cause, and a tuple slot cannot close the loop. Put the recursion behind an object, array, Map, Set or function slot. |
| A reference to a type whose file is not in the same run | Add that file to the same command. |
| A Temporal type that resolves to `any` | The Temporal declarations are missing from your project. Add the `ESNext.Temporal` lib or a polyfill's types. Converting would make the `any` permanent. |

A generic type (`type Box<T> = ...`) is not an error: a type parameter has no runtime shape, so there is nothing to convert. The declaration is reported and left as written, and every use with real types converts normally.

A test covers every row: [unsupported-conversion.test.ts](https://github.com/MionKit/mion/blob/main/packages/run-types/test/features/unsupported-conversion.test.ts).

Converting to plain types leaves a builder const alone if your code still uses it elsewhere.

## Dry Runs

`--check` reports what would change without writing, and exits with code 1 while anything is pending.

```bash
npx mion convert --to type --check src/models/
```

## Output Folders

`--out-dir` writes the converted files into a copy of the folder and leaves your sources untouched.

```bash
npx mion convert --to builders src/models/ --out-dir converted/
```
