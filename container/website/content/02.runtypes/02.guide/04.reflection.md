Reflection gives you your TypeScript types at runtime: a short, stable id, or a RunType node you can walk. Validation, serialization and mocks read the same graph. Each type is one node, with a `kind` and links to the inner types it holds.

## RunType Node Fields

Every node has a `kind`, one of the `RunTypeKind` values. The rest depends on that kind, but the edges that hold inner types are always one of these:

- `child` is the single inner type, like an array's element, a promise's value, or a property's type.
- `children` are the inner types of a container, like an object's properties, a union's members, or a tuple's slots.
- `parameters` and `return` are a function's argument nodes and its return node.

Members also carry `name` and `optional`, literals and enums carry `literal` and `values`, and a branded [TypeFormat](/runtypes/guide/type-formats) carries `formatAnnotation`.

A `formatAnnotation` holds the canonical format `name` (`uuid`, `email`, `dateTime`) and optional `params` with that format's constraints. To map a format onto a database column or a UI label, look its name up in `typeFormats`: every built-in format name with the base kind it refines. Import `typeFormats` and the `FormatName` union of its names from `@mionjs/run-types/runtime`.

Names come from your source, including tuple labels and function parameter names. Two tuples with the same element types but different labels are two reflected types, each with its own labels.

::note
Builtin classes (Date, Map, Set, Temporal) carry a `subKind` and a name instead of `children`, so treat them as leaves. Detect them by `subKind` (`node.subKind === RunTypeSubKind.date`), not by name: your own class could also be called Date. `RunTypeSubKind` comes from the package root, like `RunTypeKind`.
::

## RunType Node Kinds

A node's `kind` is always one of these, grouped by how you walk it:

```text
Atomic (leaves)    string  number  boolean  bigint  symbol  null  undefined  void
                   never  any  unknown  object  regexp  literal  templateLiteral  enum
Single child       array  promise  rest                      (read child)
Containers         tuple  union  intersection  objectLiteral  (read children)
Members            property  propertySignature  parameter  tupleMember  indexSignature
Callables          function  method  callSignature  methodSignature  (read parameters, return)
Class              class, covering Date / Map / Set / Temporal or a plain shape (read subKind)
Type level (rare)  typeParameter  infer  enumMember  ref
```
