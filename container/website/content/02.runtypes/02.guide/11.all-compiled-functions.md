RunTypes compiles one function per job, and each has a factory. The full list is at the end of this page.

::tip
A function is compiled only where you ask for it. A type you only validate never gets an
encoder.
::

## Calling Every Factory

Each factory takes your type and returns a compiled function. Its options pick which one: `createValidateFn<T>()` and `createValidateFn<T>(undefined, {checkUnknowns: true})` compile two different functions.
