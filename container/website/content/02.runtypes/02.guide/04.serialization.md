Serialization is a round trip: any JavaScript data value you send over the wire comes back as the same value, including `bigint`, `Date`, `Map` and `Set`. RunTypes builds the encoder and decoder from your type at build time, in two formats: JSON and binary.

## Function Calls Over the Wire

Any parameter or return value a function declares survives the round trip. You can call a function on another machine with the same values you would pass locally.

::

## Check Decoded Data

Decoders do not validate. They convert what they find and trust the shape. For data from outside your app, validate the decoded value.

<code-import path="packages/examples/src/guide/serialization-validate-decoded.ts" lang="ts" />

::tip
A decoder only converts the exact form the encoder writes. A Date field holding `null` or a number stays as it is, so the validator rejects it.
::

## Values That Are Not Data

Functions, methods, symbols, promises, `RegExp` and typed arrays like `Int8Array` are not data. RunTypes handles them by position:

- **As a property or a union member**, they are left out. The build shows a warning.
- **As the whole type, an array item or a tuple slot**, the build fails with an error.

Decoders return `DataOnly<T>`, your type without those members.

## Circular References

Recursive types work, like a tree or a linked list. A value that points back to itself does not: by default the encoder does not check, and the loop ends in a `RangeError` from the JavaScript stack.

Pass `rejectCircularRefs: true` to the JSON or binary encoder to get a `CircularReferenceError` instead. It throws before anything is written, with the path to the loop.

<code-import path="packages/examples/src/guide/serialization-circular.ts" lang="ts" />

::note
`rejectCircularRefs` must be written as a literal in the call. The build reads it, so a variable has no effect.
::

## Classes

A class instance encodes like an object with the same properties, and decodes to a plain object by default. Register the class with `registerClassSerializer` from `@mionjs/run-types/runtime` to get real instances back.

Pass `deserialize` when the constructor takes arguments. Without it, RunTypes creates the instance and copies the properties in. Pass `serialize` to change what is written, keeping it to the declared properties on the JSON path.

<code-import path="packages/examples/src/guide/serialization-class.ts" lang="ts" />

::note
One registration covers both JSON and binary, and every generic version of the class. `Date`, `Map` and `Set` have their own handling and cannot be registered.
::
