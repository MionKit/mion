Serialization is a round trip: any JavaScript data value you send over the wire comes back as the same value, including `bigint`, `Date`, `Map` and `Set`. `createJsonEncoderFn<T>()` returns a function that turns a value into a JSON string. `createJsonDecoderFn<T>()` returns a function that turns the string back into your type.

<code-import path="packages/examples/src/guide/serialization-overview.ts" lang="ts" commentStart="// start-json" commentEnd="// end-json" />

::note
The build only writes code for what JSON does not support directly, like `Date`, `bigint`, `Map` or unions. When nothing needs converting, no code is written and the function is marked `isNoop` (no operation).
::

## What the JSON Looks Like

Types that JSON supports stay as they are. The others become strings or arrays, and the decoder converts them back.

<code-import path="packages/examples/src/guide/json-wire-format.ts" lang="ts" commentStart="// start-types" commentEnd="// end-types" />

- A missing optional property stays missing.
- `undefined` in an array or tuple becomes `null`, so the positions stay the same.
- `NaN`, `Infinity` and `-Infinity` become `null`, as with `JSON.stringify`.

## Union Encoding

A union whose members are all plain JSON (strings, numbers, booleans, `null`) stays as it is. When a member needs converting, like a `Date` or a `bigint`, the value is written as `[index, value]`. The index tells the decoder which member to rebuild.

<code-import path="packages/examples/src/guide/json-wire-format.ts" lang="ts" commentStart="// start-unions" commentEnd="// end-unions" />

::tip
Only a RunTypes decoder for the same type can read the index. If another tool reads your JSON, keep union members to plain JSON values.
::

## JSON Strategies

The `strategy` option sets what happens to properties your type does not declare. Use the same one on the encoder and the decoder.

<code-import path="packages/examples/src/guide/json-strategies.ts" lang="ts" commentStart="// start-strategies" commentEnd="// end-strategies" />

| Strategy | Undeclared properties | Changes your value |
|---|---|---|
| `clone` (default) | dropped | no, builds a new value |
| `mutate` | kept | yes, converted in place |
| `compact` | dropped, and property names are not written | no |

- With `mutate`, an undeclared property goes to `JSON.stringify` untouched. An undeclared `bigint` makes it throw.
- `compact` writes each object as a smaller array of its values, in the order your type declares them.
- With `compact`, a missing optional property is written as `null`. So for an optional property typed `T | null`, a `null` value and a missing value both decode to `undefined`.

::note
Write the options as a literal object in the call, `rejectCircularRefs` included. A variable is ignored and the defaults apply.
::

::

## Values That Are Not Data

Functions, methods, symbols, promises, `RegExp` and typed arrays like `Int8Array` are not data. RunTypes handles them by position:

- **As a property or a union member**, they are left out. The build shows a warning.
- **As the whole type, an array item or a tuple slot**, the build fails with an error.

Decoders return `DataOnly<T>`, your type without those members.

## Circular References

Recursive types work, like a tree or a linked list. A value that points back to itself does not: by default the loop ends in a `RangeError` from the JavaScript stack. Pass `rejectCircularRefs: true` to the JSON encoder to throw a `CircularReferenceError` instead, before anything is written, with the path to the loop.

## Classes

A class instance encodes like an object with the same properties, and decodes to a plain object by default. Register the class with `registerClassSerializer` from `@mionjs/run-types/runtime` to get real instances back.

Pass `deserialize` when the constructor takes arguments. Without it, RunTypes creates the instance and copies the properties in. Pass `serialize` to change what is written, keeping it to the declared properties.

<code-import path="packages/examples/src/guide/serialization-class.ts" lang="ts" />

::note
One registration covers every generic version of the class. `Date`, `Map` and `Set` have their own handling and cannot be registered.
::
