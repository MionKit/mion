RunTypes compiles a function per job, not one do-everything validator. This is the whole list: what each one does, the `createX` that builds it, and the options that change it.

You will not use most of them directly. The ones with a factory are the everyday API. The ones without are the smaller pieces the string encoders and decoders are made of, and you only reach for those when you own your own JSON envelope (see [Compiler Markers](/runtypes/guide/compiler-markers#requesting-functions-that-have-no-factory)).

::tip
Each function is compiled only where you ask for it. A type you only validate never gets an encoder, so the list being long costs your bundle nothing.
::

::note
"Emitted as" is the short name the generated code uses internally. You never write it: a marker names the function by its readable name. The two are kept apart so the names can stay clear without making the generated code bigger.
::
