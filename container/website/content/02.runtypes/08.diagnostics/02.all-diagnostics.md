Every code RunTypes can report, grouped by feature. Search any text (a code, a word from the message, a type name), or filter by level and feature. Each entry shows the message, a type that triggers it, and how to fix it. The levels are explained in [Error Levels](/runtypes/diagnostics/error-levels).
