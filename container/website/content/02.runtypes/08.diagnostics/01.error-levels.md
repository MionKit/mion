Error and RuntimeError both print the word `error`, so check the code to see which one you got. Every code is listed in [All Diagnostics](/runtypes/diagnostics/all-diagnostics).

## Disabling Errors

Two comments turn an error off:

- `@mion-expect-error` hides it.
- `@mion-downgrade-error` shows it as a warning, so the build does not fail.

Use `//` above a line to cover that line. Use `/* */` at the top of the file, before any code, to cover the whole file.

<code-import path="packages/examples/src/guide/disabling-errors.ts" lang="ts [disabling-errors.ts]" />

| Comment | Placement | What happens |
| --- | --- | --- |
| `// @mion-expect-error VL002` | its own line | VL002 on the next line is hidden |
| `// @mion-downgrade-error VL002` | its own line | VL002 on the next line becomes a warning |
| `/* @mion-expect-error VL002 */` | top of the file | every VL002 in the file is hidden |
| `/* @mion-downgrade-error VL002 */` | top of the file | every VL002 in the file becomes a warning |
| `/* @mion-expect-error */` | top of the file | every error in the file is hidden |

Put several codes on one comment, split by spaces or commas. A comment that turns nothing off is reported (`EXP001` or `DWN001`), so it cannot sit there forever. An Error can never be turned off.

::tip
Always name the code. A comment with no code also hides errors you have not seen yet, including new ones. Use it only when the whole file is meant to be that way.
::

## Downgrading Errors in Config

`downgradeErrors` turns the codes you list into warnings, across the whole project. Use it when you cannot add a comment: the type is in a package you do not own, or the problem is in your config.

::code-group
```ts [vite.config.ts]
mionVitePlugin({
  runTypes: {
    downgradeErrors: ['CTA003'],
  },
});
```
```json [tsconfig.json]
{
  "compilerOptions": {
    "plugins": [{"name": "mion", "downgradeErrors": ["CTA003"]}]
  }
}
```
::

It still prints on every build, tagged so you can tell it from a plain warning:

```
node_modules/some-lib/adapter.js(41,9): warning CTA003: ... (downgraded)
```

All the options are listed in [Configuration](/runtypes/introduction/configuration#option-reference).

::tip
`'*'` turns every code into a warning at once, which helps when adding mion to an existing project. List the real codes once you know them. An Error is never downgraded, not even by `'*'`.
::
