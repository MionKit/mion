## Declaring a Collection Format

Arrays, objects, Maps and Sets keep the shape you wrote in TypeScript. Limits on the collection itself go in one options object, with one wrapper per collection kind.

<code-import path="packages/examples/src/guide/structural-formats.ts" lang="ts" commentStart="// start-array" commentEnd="// end-array" />

| | Type-first | Type Builder |
| --- | --- | --- |
| Arrays and tuples | `TF.FormattedArray<T[], {...}>` | `RT.array(item, {...})` |
| Objects and records | `TF.FormattedObject<Shape, {...}>` | `RT.object(config, {...})`, `RT.record(inner, {...})` |
| Sets | `TF.FormattedSet<Set<T>, {...}>` | `RT.set(item, {...})` |
| Maps | `TF.FormattedMap<Map<K, V>, {...}>` | `RT.map(key, value, {...})` |

::tip
No TypeScript type says "an array whose entries differ", so `uniqueItems` keeps the closest shape (`string[]`) and the generated function does the check.
::

## Collection Options

An entry is one item of an array, one member of a Set, or one `[key, value]` pair of a Map. On a Map, put `unknown` in the half of `contains` you do not care about.

<code-import path="packages/examples/src/guide/structural-formats.ts" lang="ts" commentStart="// start-contains" commentEnd="// end-contains" />

| Option | On | What it asks |
| --- | --- | --- |
| `minItems` / `maxItems` | every collection | how many entries there may be |
| `uniqueItems` | every collection | no two entries are equal, compared by value |
| `contains` | every collection | at least one entry matches a second type |
| `minContains` / `maxContains` | every collection | how many entries must match `contains` |
| `minProperties` / `maxProperties` | objects | how many keys the value may carry |
| `patternProperties` | objects | keys matching a pattern carry a given type |
| `propertyNames` | objects | every key satisfies a string format |

::note
These are JSON Schema's own options and names, so a [generated JSON Schema document](/runtypes/guide/json-schemas) enforces exactly what the type does. A bounded Set or Map declares them on the array it travels as.
::
