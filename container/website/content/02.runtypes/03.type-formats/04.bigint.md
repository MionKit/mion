## Named BigInt Formats

Each format is a `TF.BigInt` with its params set, and has a builder named in lowercase (`TF.bigInt64()`, `TF.bigPositive()`). For your own bounds, use `TF.BigInt` directly (see [Custom Formats](/runtypes/type-formats/overview#custom-formats)).

| Format | Accepts |
| --- | --- |
| `TF.BigPositive`, `TF.BigPositiveInt` | `>= 0n` |
| `TF.BigNegative`, `TF.BigNegativeInt` | `<= 0n` |
| `TF.BigInt64` | a value that fits a signed 64-bit integer |
| `TF.BigUInt64` | a value that fits an unsigned 64-bit integer |

::tip
Bounds on a bigint format are `bigint` literals: write `TF.BigInt<{min: 0n}>`, not `{min: 0}`.
::
