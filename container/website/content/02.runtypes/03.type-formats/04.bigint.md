## Named BigInt Formats

Each format is a `TF.BigInt` with its params set, and has a builder named in lowercase (`TF.bigInt64()`, `TF.bigPositive()`). For your own bounds, see [Custom BigInt Formats](#custom-bigint-formats).

<code-import path="packages/examples/src/guide/type-formats-number.ts" lang="ts" commentStart="// start-bigint-named" commentEnd="// end-bigint-named" />

| Format | Accepts |
| --- | --- |
| `TF.BigPositive`, `TF.BigPositiveInt` | `>= 0n` |
| `TF.BigNegative`, `TF.BigNegativeInt` | `<= 0n` |
| `TF.BigInt64` | a value that fits a signed 64-bit integer |
| `TF.BigUInt64` | a value that fits an unsigned 64-bit integer |
