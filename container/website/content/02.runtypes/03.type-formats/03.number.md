## Named Number Formats

Each format is a `TF.Number` with its params set, and has a builder named in lowercase (`TF.int32()`, `TF.positive()`). For your own bounds, use `TF.Number` directly (see [Custom Type Formats](/runtypes/type-formats/overview#custom-type-formats)).

| Format | Accepts |
| --- | --- |
| `TF.Integer` | a whole number |
| `TF.Float` | any number; mocks draw fractional values and binary keeps the full 8 bytes |
| `TF.Positive` / `TF.Negative` | `>= 0` / `<= 0` |
| `TF.PositiveInt` / `TF.NegativeInt` | a whole number `>= 0` / `<= 0` |
| `TF.Int8`, `TF.Int16`, `TF.Int32` | a whole number that fits the signed width |
| `TF.UInt8`, `TF.UInt16`, `TF.UInt32` | a whole number that fits the unsigned width |
| `TF.Currency` | any number, marked as money |

::tip
`TF.Positive` and `TF.Negative` include zero. Write `TF.Number<{gt: 0}>` for a strictly positive number.
::

## Currency

`TF.Currency` (builder `TF.currency()`) sets the `isCurrency` param on `TF.Number`. It validates and serializes like `TF.Number`, and [friendly error messages](/runtypes/ai-integration/i18n#money-in-messages) show a broken limit with the currency symbol and decimals of the reader's language.
