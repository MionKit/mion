Some JavaScript values have no word in standard JSON Schema. A `Date`, a `Map`, a bigint and a Temporal instant all travel as ordinary JSON, but nothing in the standard says what the JSON turns back into once it is decoded. This document specifies the small extension RunTypes adds for exactly that, used by the [convert command](/guide/converting-forms) and by [schemas you write yourself](/guide/json-schema).

It is an extension, never a replacement. Every keyword here sits beside the standard keywords describing the same value, so a plain 2020-12 validator still enforces the whole JSON contract and simply ignores the extra words. Delete every one of them and no validator changes its mind about any value.
