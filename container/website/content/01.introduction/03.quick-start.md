## 1. Install

You need two things: the runtime package and the Vite plugin that reads your types.

::code-group
```bash [pnpm]
pnpm add @ts-runtypes/core
pnpm add -D @ts-runtypes/devtools
```
```bash [npm]
npm install @ts-runtypes/core
npm install -D @ts-runtypes/devtools
```
```bash [yarn]
yarn add @ts-runtypes/core
yarn add -D @ts-runtypes/devtools
```
::

::note
RunTypes is the only thing that ends up in your runtime bundle, and it carries no dependencies. `@ts-runtypes/devtools` does its work at build time and ships nothing to production.
::

## Other bundlers

Vite is the shortest path, but the same plugin ships for Rollup, Rolldown, webpack, Rspack and esbuild. Each one has its own entry point, and every entry takes the same options.

| Bundler | Import |
| --- | --- |
| Vite | `@ts-runtypes/devtools/vite` |
| Rollup | `@ts-runtypes/devtools/rollup` |
| Rolldown | `@ts-runtypes/devtools/rolldown` |
| webpack | `@ts-runtypes/devtools/webpack` |
| Rspack | `@ts-runtypes/devtools/rspack` |
| esbuild | `@ts-runtypes/devtools/esbuild` |

<code-import path="packages/examples/src/introduction/quick-start-rollup-config.ts" lang="ts" />

The rewrite is identical whatever bundler runs it, so your generated code does not change when you switch. The Vite entry adds hot reload on top, and for a tool that is not on the list, `@ts-runtypes/devtools/unplugin` exposes the framework-agnostic [unplugin](https://github.com/unjs/unplugin) instance the others are built from.
