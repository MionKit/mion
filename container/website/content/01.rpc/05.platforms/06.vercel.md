`@mionjs/platform-vercel` runs mion as Next.js App Router route handlers. It returns `GET`, `POST`, `PUT`, `DELETE` and `PATCH` handlers that you re-export from a catch-all route file.

## Installing the Adapter

```bash
npm install @mionjs/platform-vercel @mionjs/router
```

## Catch-all Route

One route file handles every method. Place it in a Next.js App Router catch-all directory, whose `[...mion]` segment sends every path under `/api/` to mion's router.

```
app/
  api/
    [...mion]/
      route.ts   ← exports GET/POST/PUT/DELETE/PATCH from createVercelHandler()
```

The same handler also hosts your API inside a Next app, see [Hosting the API in Your Next App](/rpc/devtools/nextjs#hosting-the-api-in-your-next-app).

## API Base Path

Set `basePath: '/api'` on the [router](/rpc/server/routes#creating-the-router) **and** the client, and point the client's `baseURL` at the origin. Putting `/api` in `baseURL` does not work: a route path is absolute, so it replaces the base's path and drops the prefix.

```ts
// your routes module
const mion = createMionRouter({basePath: '/api'});

// your client
const {routes} = initClient<MyApi>({baseURL: 'https://your-app.vercel.app', basePath: '/api'});
```

## Handler Options

Pass options such as `maxBodySize` (128 KB by default) and `maxBodySizeCap` to `createVercelHandler`. `maxBodySizeCap` defaults to the 4.5 MB Vercel allows, and Vercel refuses anything bigger before the function runs; override it if Vercel changes it. Each route has its own [body limit](/rpc/server/security#body-size-limits), and a body stream past it is cancelled with a 413.

::tip
The handler uses the Web standard `Request -> Response` API, so it runs on both the Node.js and Edge runtimes without changes.
::

::caution
The **Edge runtime** forbids `new Function()` and `eval()`, so an Edge build must set
`runTypes: {emitMode: 'both'}` on the [mion Vite plugin](/rpc/devtools/vite):

```ts [vite.config.ts]
mionVitePlugin({
    runTypes: {
        tsConfig: resolve(__dirname, 'tsconfig.json'),
        // required on Edge: no `new Function` at runtime
        emitMode: 'both',
    },
}),
```

Otherwise `mion.initRoutes` fails with *"Code generation from strings disallowed for this context"*.
See [Cloudflare Workers](/rpc/platforms/cloudflare#vite-configuration) for why, and the bundle-size cost.
Node.js-runtime deployments need no such change.
::

:spacer
