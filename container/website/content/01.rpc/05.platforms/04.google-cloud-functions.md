## Deployment

Deploy with the gcloud CLI:

```bash
gcloud functions deploy api \
  --runtime nodejs22 \
  --trigger-http \
  --allow-unauthenticated
```

## Adapter Options

Pass options such as `maxBodySize` (128 KB by default) and `maxBodySizeCap` to `createGoogleCFHandler`. `maxBodySizeCap` defaults to the 10 MB Google allows on a 1st gen function; override it on 2nd gen (32 MB). Set router options like `basePath` once in [`createMionRouter`](/rpc/server/routes#creating-the-router), and see [Security](/rpc/server/security#body-size-limits) for body limits.
