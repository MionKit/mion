## Installing the Adapter

```bash
npm install @mionjs/platform-uws @mionjs/router
```

The native uWebSockets.js binaries install automatically, as per-platform packages npm picks for your machine, with no compiler or extra steps.

::caution
uWebSockets.js publishes prebuilt binaries only for even Node.js versions (currently 22, 24 and 26) on Linux (glibc), macOS and Windows x64. On other Node versions or on Alpine Linux the server will not start, so use the Node.js platform there.
::

Pass options such as `maxBodySize` to `startUwsServer`, and set router options like `basePath` once in [`createMionRouter`](/rpc/server/routes#creating-the-router). Each route has its own [body limit](/rpc/server/security#body-size-limits), and the native read stops at it.

::tip
uWebSockets.js is a native C++ server and one of the fastest HTTP servers for Node.js. It suits high throughput APIs on your own machines or containers.
::

::note
The mion team publishes the binaries on npm, unmodified from the pinned official [uWebSockets.js](https://github.com/uNetworking/uWebSockets.js) release (Apache 2.0 license).
