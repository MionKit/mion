## Configuration

You can pass configuration options to `initMionHttp`:

<code-import path="packages/examples/src/http/node-config.ts" lang="ts" />

The `maxBodySize` option (256 KB by default) is enforced while the body is read: a `content-length` past the limit is refused before a byte is read, a body that grows past it is refused mid-stream with a 413, and the router honours the same number. See [Security](/rpc/server/security) for the limits on every platform.

::tip
For production deployments, consider using a process manager like PM2 or running behind a reverse proxy like nginx.
::

## Mounting mion in a server you own

Set `asMiddleware` and mion registers everything — routes, options, platform config — but never calls `listen()`: the host owns the socket. `httpRequestHandler` is then yours to mount wherever you want it, in an express/connect app or your own `http.createServer`.

<code-import path="packages/examples/src/http/node-middleware.ts" lang="ts [src/middleware.ts]" />

This is also what powers the Vite plugin's [`runMode: 'middleware'`](/rpc/devtools/vite): it flips the same option before loading your entry, so an unchanged `initMionRouter(); startNodeServer();` server runs inside the dev server without opening a port of its own.

:spacer
