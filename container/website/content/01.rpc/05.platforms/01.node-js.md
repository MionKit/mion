## Adapter Options

Pass options such as `maxBodySize` to `startNodeServer`, and set router options like `basePath` once in [`createMionRouter`](/rpc/server/routes#creating-the-router). Each route has its own [body limit](/rpc/server/security#body-size-limits): a `content-length` over it is refused before reading, and a body that grows past it is refused mid-stream with a 413.

<code-import path="packages/examples/src/http/node-config.ts" lang="ts" />

::tip
In production, consider a process manager like PM2 or a reverse proxy like nginx.
::

## Mounting mion in Your Own Server

With `asMiddleware`, mion sets everything up but never calls `listen()`. Mount `httpRequestHandler` wherever you want, in an express/connect app or your own `http.createServer`. The [Vite plugin](/rpc/devtools/vite) sets this option to run an unchanged `mion.initRoutes(routes); startNodeServer();` entry inside its dev server, without opening a port.
