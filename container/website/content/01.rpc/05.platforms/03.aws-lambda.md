## API Gateway Configuration

mion works with both REST API and HTTP API (v2). Configure a catch-all route:

```yaml
# serverless.yml example
functions:
  api:
    handler: src/handler.handler
    events:
      - httpApi:
          method: '*'
          path: '/{proxy+}'
```

::tip
When API Gateway or a Lambda Function URL sends a base64 body (`isBase64Encoded: true`, common with binary media types), the handler decodes it first. `maxBodySize` measures the decoded text.
::

## Adapter Options

Pass options such as `maxBodySize` (128 KB by default) and `maxBodySizeCap` to `createAwsLambdaHandler`. `maxBodySizeCap` defaults to the 6 MB AWS allows on a synchronous invocation; override it when your entry path differs (1 MB behind an Application Load Balancer). Set router options like `basePath` once in [`createMionRouter`](/rpc/server/routes#creating-the-router), and see [Security](/rpc/server/security#body-size-limits) for body limits.
