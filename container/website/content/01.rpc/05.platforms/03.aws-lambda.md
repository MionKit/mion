mion can run on AWS Lambda for serverless deployments. The `@mionjs/platform-aws` package provides a handler compatible with API Gateway events.

## Installation

```bash
npm install @mionjs/platform-aws @mionjs/router
```

## API Gateway Configuration

mion works with both REST API and HTTP API (v2) in API Gateway. Make sure to configure a catch-all route:

```yaml
# serverless.yml example
functions:
  api:
    handler: src/handler.handler
    events:
      - httpApi:
          method: '*'
          path: '/{proxy+}'
```

::tip
When API Gateway or a Lambda Function URL delivers the body base64 encoded (`isBase64Encoded: true`, common with binary media types), the handler decodes it first, so the request is served exactly like a plain one and the `maxBodySize` limit measures the decoded text.
::

## Configuration

You can pass configuration options to `createAwsLambdaHandler`, among them `maxBodySize`: the request limit a route takes when its own option is unset and its types cannot say (128 KB by default). AWS caps a synchronous invocation's request at 6 MB (1 MB behind an Application Load Balancer), which no option can raise: the adapter carries it as `AWS_LAMBDA_MAX_BODY_SIZE_CAP`, and `maxBodySizeCap` overrides it when your entry path differs. The platform hands the handler the whole body, so the route limit is checked before parsing rather than mid-flight. Router options like `basePath` are set once in `createMionRouter`, see [Creating the Router](/rpc/server/routes#creating-the-router) and [Security](/rpc/server/security#body-size-limits).
