## Cloudflare Configuration

A minimal `wrangler.toml` for a mion Worker, where `main` points to the [Vite](#vite-configuration) bundle. Run `wrangler deploy` to publish.

```toml
name = "my-mion-api"
main = "dist/worker.js"
compatibility_date = "2024-01-01"
```

## Handler Options

Pass options such as `maxBodySize` (128 KB by default) and `maxBodySizeCap` to `createCloudflareHandler`. `maxBodySizeCap` defaults to the 100 MB Cloudflare allows on the Free and Pro plans; override it on Business or Enterprise, which allow more. The handler's `basePath` strips a URL prefix before routing. Router options, including the router's own `basePath`, go in [`createMionRouter`](/rpc/server/routes#creating-the-router). Each route has its own [body limit](/rpc/server/security#body-size-limits), and a streamed body is cancelled with a 413 the moment it passes it.

::tip
The handler puts `env` (your Worker bindings: KV, D1, R2, secrets, etc.) and `ctx` (the Worker `ExecutionContext` with `waitUntil`/`passThroughOnException`) on the call context's platform context. Use it to read Worker bindings in your route handlers.
::

## Vite Configuration

A minimal `vite.config.ts` for a Worker. The Worker entry needs no special setup beyond [Creating the Handler](#creating-the-handler).

::caution
Cloudflare Workers do not allow `new Function()` or `eval()`, so a Worker build **must** set
`runTypes: {emitMode: 'both'}` on the [mion Vite plugin](/rpc/devtools/vite).

The default `emitMode: 'code'` ships each build-time compiled function as a *source string* that
`new Function` turns into a real function on first use, and `mion.initRoutes` fails on the first route
with *"Code generation from strings disallowed for this context"*. `'both'` also ships the live function,
so nothing is compiled at runtime or at cold start. The cost: roughly +30% raw bundle size, +15% gzipped.
::

## Cloudflare Databases

Cloudflare's two SQLite databases, D1 and Durable Objects storage, both work with the SQLite table package. Declare the table once and pick the driver where you connect, see [Cloudflare D1 and Durable Objects](/rpc/drizzle-orm/cloudflare-storage).
