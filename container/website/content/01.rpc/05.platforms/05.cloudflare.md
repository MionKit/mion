mion can run on Cloudflare Workers for globally-distributed edge deployments. The `@mionjs/platform-cloudflare` package provides a Web standard `Request -> Response` fetch handler with access to Worker bindings via the platform context.

## Installation

```bash
npm install @mionjs/platform-cloudflare @mionjs/router
```

## wrangler.toml Example

A minimal `wrangler.toml` for a mion Worker:

```toml
name = "my-mion-api"
main = "dist/worker.js"
compatibility_date = "2024-01-01"
```

The `main` field points to the bundled output produced by Vite (see [Vite Configuration](#vite-configuration) below). Run `wrangler deploy` to publish.

## Vite Configuration

::caution
Cloudflare Workers do not allow `new Function()` or `eval()`, so a Worker build **must** set
`runTypes: {emitMode: 'both'}` on the [mion Vite plugin](/rpc/devtools/vite).

The plugin always compiles every route's validation and serialization functions at build time — there
is no AOT step to wire up — but the default `emitMode: 'code'` ships each compiled function as a
*source string* that is turned into a real function with `new Function` the first time it runs. That is
exactly what workerd refuses, and `initMionRouter` fails on the first route with *"Code generation from
strings disallowed for this context"*. `'both'` emits the live function alongside the string, so nothing
is compiled at runtime (it also removes that work from your cold start). The cost is bundle size:
roughly +30% raw, +15% gzipped.
::

`inlineDynamicImports: true` is required because Workers don't support dynamic code splitting — every dependency must be bundled into a single file.

The Worker entry itself needs no special setup — it just registers the routes with `initMionRouter` and exports the fetch handler, exactly as shown in [Quick Start](#quick-start) above. The plugin has already replaced each route's validators with precompiled functions at build time, so there is no AOT flag, cache import, or virtual module to wire up — only the `emitMode` above, which decides whether those functions ship ready to call or as source to compile on first use.

:spacer

## Databases

Cloudflare's two SQLite databases, D1 and Durable Objects storage, both work with the SQLite table package. Declare the table once, pick the driver where you connect: see [Cloudflare D1 and Durable Objects](/rpc/drizzle-orm/cloudflare-storage).
