## Adapter Options

Pass options such as `maxBodySize` to `startBunServer`, and set router options like `basePath` once in [`createMionRouter`](/rpc/server/routes#creating-the-router). Each route has its own [body limit](/rpc/server/security#body-size-limits), and a body over it is refused with a 413. Bun's own read limit is set to the largest route limit at startup, which stops an oversized upload mid-flight.
