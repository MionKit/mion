## Configuration

You can pass configuration options to `startBunServer`, among them `maxBodySize`. Router options like `basePath` are set once in `createMionRouter`, see [Creating the Router](/rpc/server/routes#creating-the-router).

<code-import path="packages/examples/src/bun/bun-config.ts" lang="ts" />

Every route has its own request limit (its option, else a number derived from its types, else this adapter's `maxBodySize`, 128 KB by default), checked by the router before the body is parsed, so it also holds in middleware mode. Bun has one server-wide read limit (128 MB out of the box), which mion sets to the largest limit any route resolves to when the server starts. See [Security](/rpc/server/security#body-size-limits) for the whole rule.

::tip
Bun's native HTTP server is extremely fast and can handle high throughput workloads efficiently.
::
