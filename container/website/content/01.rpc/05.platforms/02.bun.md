## Configuration

You can pass configuration options to `startBunServer`, among them `maxBodySize`. Router options like `basePath` are set once in `createMionRouter`, see [Creating the Router](/rpc/server/routes#creating-the-router).

<code-import path="packages/examples/src/bun/bun-config.ts" lang="ts" />

Every route has its own request limit. Bun buffers the body natively before your code runs, so the adapter reads it with Bun's own fast path and refuses a body past the route limit with a 413. Bun's server-wide read limit is set to the largest route limit when the server starts, which is what stops an oversized upload mid-flight. See [Security](/rpc/server/security#body-size-limits).

::tip
Bun's native HTTP server is extremely fast and can handle high throughput workloads efficiently.
::
