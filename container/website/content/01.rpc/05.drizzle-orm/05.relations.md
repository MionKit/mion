## Why Relations Stay in the Query File

Your schema file stays free of Drizzle types, so a client importing its row types never type-checks or bundles your database code. The query file already loads Drizzle, so relations cost nothing extra there.

## Foreign Keys

A relation is not a foreign key. For the database to enforce the link, declare it in the schema with the `references` setting or `foreignKey()` (see [Indexes and Constraints](/rpc/drizzle-orm/constraints)).
