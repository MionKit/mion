      ## [RunTypes]{.title-tone}

      mion uses [RunTypes](/runtypes/introduction/about-mion-runtypes) behind the scenes to generate validation and JSON round trip functions from your TypeScript types, at build time.
      RunTypes supports advanced [type formats](/runtypes) and can be used as a standalone library.

      [No schema libraries needed. TypeScript is the single source of truth.]{.text-highlighted}

#title
[Vertical]{.title-tone} Integration

#body
  :::div{class="text-center"}
    Most modern stacks are tools glued together (validation, routing, JSON round trip, client generation), all wired manually. mion replaces that with a single integrated system, reducing boilerplate, inconsistencies, and maintenance overhead.
    <br>
    :vertical-integration
  :::

#title
[Solid]{.title-tone} Performance

#body
  Routes are looked up in memory rather than matched against a URL pattern, validation and the JSON round trip are compiled at build time, and routes load on demand so a cold start has little to do. The result is measured against the fastest frameworks on every deploy.
