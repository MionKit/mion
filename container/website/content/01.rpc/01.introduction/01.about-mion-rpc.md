    ### RunTypes <sup>©</sup>
    mion use [RunTypes](/runtypes/introduction/about-mion-runtypes) behinds the scene to generate JIT-compiled validation and serialization functions directly from TypeScript types.
    RunTypes supports advanced [type formats](/runtypes) and can be used as a standalone library.

    [No schemas libraries needed — Typescript is the single source of truth.]{.text-highlighted}

#title
Solid Performance

#body
  Routes are looked up in memory rather than matched against a URL pattern, validation and serialization are compiled at build time, and routes load on demand so a cold start has little to do. The result is measured against the fastest frameworks on every deploy.
