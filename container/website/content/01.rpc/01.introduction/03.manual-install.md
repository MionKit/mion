## Installing the Router

```bash
npm i @mionjs/core @mionjs/router
npm i -D @mionjs/devtools
```

## Installing a Platform

Install the package for where you run mion. For local development use Node or Bun.

::code-group
```bash [Node.js]
npm install @mionjs/platform-node
```

```bash [Bun]
npm install @mionjs/platform-bun
```

```bash [uWebSockets.js]
npm install @mionjs/platform-uws
```

```bash [AWS Lambda]
npm install @mionjs/platform-aws
```

```bash [Google Cloud Functions]
npm install @mionjs/platform-gcloud
```
::
