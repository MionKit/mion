## Turbopack and webpack

`withMion` picks the right setup for you. Turbopack has no plugin API, so mion starts a background process from `next.config` and registers a loader that asks it to rewrite each file. With `next --webpack`, mion uses the ordinary webpack plugin.

Only your own TypeScript is rewritten. Files in `node_modules` are left alone.

## Sharing Batches With Your API

Where the build reads your [batches](/rpc/client/batch) depends on where your API lives.

**API in this app.** Nothing to configure: the same build reads your batches and compiles them into the route handler.

**API in a separate project.** This app, the client, needs nothing either: its build gives every batch its id and every inline `inputFrom` mapper its hash. The API's own build generates the batch table and the mapper modules from this app's program, so point its Vite config at this app's tsconfig:

<code-import path="packages/examples/src/codegen/vite-server.config.ts" lang="ts [api vite.config.ts]" />

Nothing is written from this app, and there is no build order to keep. See [Batch Transport](/rpc/devtools/vite#batch-transport).

## Editing Types While the Dev Server Runs

Edit a type and every file rewritten from it recompiles, even when the type sits in a `.d.ts` with no import to follow. `next dev` stays correct without a restart.

## Options

`withMion` takes the same `runTypes`, `client`, `bundleApi` and `api` options as the Vite plugin, so see [Vite Configuration](/rpc/devtools/vite) for each. `client` is only for a Next app that hosts the mion API and serves batches to a **separate** client project. `bundleApi` and `api` are the reverse: a Next app that calls an API in another project and ships that API's compiled functions with itself:

<code-import path="packages/examples/src/codegen/next-bundled-config.ts" lang="ts [next.config.ts]" />

See [Bundling the API Into the Client](/rpc/client/bundled-api).

The Vite `server` block is refused, and the Vue single file component switch is ignored. Next runs its own dev server and builds your API route with everything else.
