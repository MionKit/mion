Constraints and indexes go in the table's third argument, a callback that receives the columns and returns an array, with the same names, parameters and chains as Drizzle. They shape the SQL, not the rows you read, so your models do not change.

## Index and Constraint Helpers

| Helper | What it makes |
| --- | --- |
| `index(name)` | a plain index |
| `uniqueIndex(name)` | a unique index |
| `unique(name)` | a unique constraint |
| `primaryKey({name, columns})` | a composite primary key |
| `foreignKey({name, columns, foreignColumns})` | a foreign key |
| `check(name, sql)` | a check constraint |
| `pgPolicy(name, config)` | a row level security policy, PostgreSQL only |

## Index and Constraint Options

Indexes take the options PostgreSQL takes:

```ts
index('idx').on(t.name.desc(), t.age).where(sql`${t.age} >= 18`);
uniqueIndex('idx').using('hnsw', t.embedding.op('vector_l2_ops'));
index('idx').on(t.name).concurrently().with({fillfactor: '70'});
```

Column position modifiers are `asc()`, `desc()`, `nullsFirst()`, `nullsLast()` and `op()`. Foreign keys take `onDelete()` and `onUpdate()`. Unique constraints take `nullsNotDistinct()`. MySQL indexes also take `algorithm()` and `lock()`.

## Inline Column Constraints

A single-column constraint can sit on the column itself:

```ts
id: uuid('id', {defaultRandom: true, primaryKey: true}),
code: varchar('code', {length: 12, notNull: true, unique: ['invites_code_uq']}),
teamId: integer('team_id', {references: [() => tableRef(teams, 'id'), {onDelete: 'cascade'}]}),
```

## Referencing Another Table

A column on another table is named with `tableRef(table, 'column')`, in a reference, a foreign key or a sql template:

```ts
import {sql, tableRef} from '@mionjs/drizzle-orm';

integer('team_id', {references: [() => tableRef(teams, 'id')]});
foreignKey({name: 'members_team_fk', columns: [t.teamId], foreignColumns: [tableRef(teams, 'id')]});
sql`select ${tableRef(teams, 'code')} from ${teams}`;
```

A table's type holds its shape (the name, the columns, the constraints), not the column objects, which keeps that type small across your app. `tableRef` checks the column name against the table. Columns of the table you are declaring come in as the callback argument (`t.teamId` above).

In a table type, a reference is `TableRef<TeamsTable, 'id'>`: `teamId: Integer<{references: [TableRef<TeamsTable, 'id'>]}>`.

::tip
A column that references its own table needs the return type written out, as in drizzle: `references: [(): TableRef<'emps', 'id'> => tableRef(emps, 'id')]`. The type takes the table name for the same reason.
::
