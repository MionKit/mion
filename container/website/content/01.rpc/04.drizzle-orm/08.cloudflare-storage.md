Cloudflare gives you two SQLite databases: [D1](https://developers.cloudflare.com/d1/) and the SQL storage inside a [Durable Object](https://developers.cloudflare.com/durable-objects/). Both are SQLite, so both use the same package you already use for SQLite.

```bash
npm install @mionjs/drizzle-orm-sqlite-core @mionjs/drizzle-orm @mionjs/run-types
npm install drizzle-orm   # only needed to run queries
```

There is no D1 package and no Durable Objects package, because there is nothing for one to do. In Drizzle ORM, `drizzle-orm/d1` and `drizzle-orm/durable-sqlite` are drivers: they know how to talk to the database and nothing else. The tables come from `drizzle-orm/sqlite-core`, which `@mionjs/drizzle-orm-sqlite-core` already covers.

So you declare a table once and pick a driver at the point where you connect.

## What you get

The same thing you get everywhere else, because it all comes from the table's types:

- routes typed with the inferred models, validated before your handler runs
- a `timestamp` column that arrives as a real `Date`, in both directions, with nothing to serialize by hand
- mock data and friendly error messages generated from the same models

Serve those routes with [@mionjs/platform-cloudflare](/rpc/platforms/cloudflare).
