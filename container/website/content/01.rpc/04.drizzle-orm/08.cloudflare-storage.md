Cloudflare has two SQLite databases: [D1](https://developers.cloudflare.com/d1/) and the SQL storage inside a [Durable Object](https://developers.cloudflare.com/durable-objects/). Both use the SQLite package.

```bash
npm install @mionjs/drizzle-orm-sqlite-core @mionjs/drizzle-orm @mionjs/run-types
npm install drizzle-orm   # only needed to run queries
```

There is no D1 or Durable Objects package: in Drizzle ORM, `drizzle-orm/d1` and `drizzle-orm/durable-sqlite` are only drivers. The tables come from `drizzle-orm/sqlite-core`, which `@mionjs/drizzle-orm-sqlite-core` already covers. You declare a table once and pick a driver where you connect.

## Features on Cloudflare

It all comes from the table's types, as on any other database:

- routes typed with the inferred models, validated before your handler runs
- a timestamp column that arrives as a real `Date`, in both directions, with nothing to serialize by hand
- mock data and friendly error messages generated from the same models

Serve those routes with [@mionjs/platform-cloudflare](/rpc/platforms/cloudflare).
