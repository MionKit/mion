A route is a function your client calls remotely. Its first parameter is always the [Call Context](/rpc/server/call-context). The rest come from the client, validated before the route runs.

Your API is a plain object of routes and middleware, with no URLs to write. Each route gets a URL underneath, which the [client](/rpc/client/client-overview) handles for you.

## Creating the Router

Create the router once per app with `createMionRouter` and pass it every router option (base path, parser, context data factory and the rest). Every helper it returns (`route`, `query`, `mutation`, `middleware`, `headersMiddleware`, `rawMiddleware`) gets those options by type.

<code-import path="packages/private-examples/src/router/full-example.routes.ts" lang="ts" commentStart="// start-create-router" commentEnd="// end-create-router" />

::tip
Create the router and call `initRoutes` in your routes file, then import that file from the server entry. Destructuring the helpers is fine: `const {route, middleware} = createMionRouter({...})`.
::

::warning
Call `createMionRouter` and `initRoutes` once each, with all your routes in one `initRoutes` call. A second call to either throws.
::

## Query and Mutation Handlers

The `query` and `mutation` helpers declare what a route does, so the client can choose how to send it. A `query` sends small payloads in the URL as a GET, a `mutation` always in the body. A `mion.route()` declares no intent, sends its data in the body and has no cache semantics.

<code-import path="packages/private-examples/src/router/query-mutation-definition.routes.ts" lang="ts" />

::tip
Prefer `mion.query()` and `mion.mutation()`: your code reads better, and it leaves room for future optimizations like caching layers.
::

## Undeclared Properties

By default, a param property your types do not declare is dropped while the request is decoded, not at validation. The `clone` and `compact` strategies rebuild the params from your declared type.

To reject the request instead, set `parser: {params: 'mutateStrict'}`. See [Validation](/rpc/server/validation#undeclared-properties).

## Request Size

mion works out the largest valid request for each route from the parameter types of the route and its middleware. A bigger request gets a 413 error, as early as the platform allows. You write no size limits by hand.

<code-import path="packages/private-examples/src/router/security-max-body-size.ts" lang="ts" />

The first limit that applies wins:

| Limit | Used when |
| --- | --- |
| `maxBodySize` on the route | You set it on the route options. |
| From the types | Every parameter has a maximum, like a string with `maxLength` or an array, Set or Map with `maxItems`. The limit is the largest valid JSON body, times `maxBodySizeFactor` (a router option, 2 by default). |
| `maxBodySize` on the platform adapter | A parameter has no maximum, like a plain `string`, `string[]`, `Map`, record or `any`. 128 KB by default. |

::tip
Give every parameter a maximum, so each route gets its own exact limit instead of the platform default.
::

::note
Responses are not limited. To turn off limits from the types, set `derivedPayloadLimits: false` in the `runTypes` block of the Vite plugin or `withMion`.
::

## Platform Ceilings

Some platforms refuse a request past their own ceiling before mion runs, and no route limit goes above it. Each platform page lists its ceiling, and the adapter's `maxBodySizeCap` option sets it.

```ts
import {createCloudflareHandler} from '@mionjs/platform-cloudflare';

// a bigger plan allows more than the default ceiling
createCloudflareHandler({maxBodySizeCap: 200_000_000});
```

## Keeping the Raw Body

Once the body is parsed mion drops the raw text, so `ctx.request.rawBody` reads empty in your handlers. Set `releaseRawBody: false` in `createMionRouter` to keep it, for an access log that records exactly what arrived.

## Awaiting Every Step

mion awaits every middleware and route in the chain. Set `alwaysAwait: false` to skip the await on
synchronous handlers: faster, but the slowest requests can get slower under load.

```ts
const mion = createMionRouter({alwaysAwait: false});
```
