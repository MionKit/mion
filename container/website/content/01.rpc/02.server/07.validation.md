mion validates with `@mionjs/run-types`, which reads your TypeScript types at compile time and uses them at runtime.
You write no schemas and no validation code.

## Automatic Validation

The params of every route and middleware are validated before it runs, unless you set `validateParams: false`.
If validation fails, the method never runs and an `RpcError` is thrown with the validation errors.

## Undeclared Properties

The [parser](/rpc/server/serialization#parser-strategies) option picks what happens to a property your type does not declare. Dropping happens while the request is decoded, not at validation.

<code-import path="packages/examples/src/router/parser-mutate-strict.routes.ts" lang="ts" />

| Strategy | An undeclared property is |
| --- | --- |
| `clone` (default) | dropped |
| `compact` | dropped |
| `mutate` | kept |
| `mutateStrict` | rejected: the route never runs and the caller gets a `validation-error` (HTTP 422) |

::note
This table is about params, and `mutateStrict` works on params only. [Parser Strategies](/rpc/server/serialization#parser-strategies) shows what each strategy does to a return value.
::

### Unions

A union is the one shape where dropping is not enough. Its members share one list of property names, and a member with an index signature declares every property:

```ts
type Pet = {kind: 'cat'; meows: boolean} | {kind: 'dog'; barks: number};
// {kind: 'cat', meows: true, barks: 3}  ->  barks is kept

type Something = {a: string} | Record<string, number>;
// {a: 'x', evil: 'garbage'}  ->  the whole object is kept

type Loose = {a: string} | Record<string, string>;
// {a: 'x', evil: 'garbage'}  ->  accepted, every value is a string
```

Every strategy checks this: `clone`, `compact` and `mutateStrict` reject the request, `mutate` still keeps the property.

The check runs only when the union has two or more members with named properties, so `{a: string} | number` is not affected.

### Checking Types Outside a Route

`checkUnknowns` rejects an undeclared property anywhere in the type, `checkUnionUnknowns` only on a union member. `mutateStrict` uses the first, `clone` and `compact` the second. See [Checking for Unknown Keys](/runtypes/guide/validation#checking-for-unknown-keys).

## Sanitizing Params

`sanitizeParams` is off by default. Turn it on and a route applies every [transform](/runtypes/type-formats/string#string-transformations) its params types declare: trim spaces, lowercase an email, strip the grouping from a card number. It runs after decoding and before validation, so a value that passes only once trimmed is accepted and the handler gets the clean value. Headers and return values are never sanitized, and it works even when `validateParams` is off.

<code-import path="packages/examples/src/router/sanitize-params-example.routes.ts" lang="ts" />

::note
A value with the wrong shape (a number where a string is expected) skips the transform, and validation reports the error.
::
