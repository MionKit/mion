# @mionjs/drizzle-orm

Dialect-agnostic core of the mion drizzle packages: slim column and table recorders, flat model types and type-level refinement. The dialect packages (`@mionjs/drizzle-orm-pg-core`, `@mionjs/drizzle-orm-mysql-core`, `@mionjs/drizzle-orm-sqlite-core`) build their authoring surface on it and re-export everything you need, so you normally install one of those instead.

Part of the mion framework, the sibling of the `@ts-runtypes/*` packages. Full documentation lives at [mion.pages.dev](https://mion.pages.dev/) and [runtypes.pages.dev](https://runtypes.pages.dev/).
