# Drizzle reference app: type cost per route

GENERATED by packages/private-drizzle-example-app/test/cost.compile.test.ts. Net type instantiations of one route.
`params` is the route with only its params; `return` is the rest (the query and the return type); `both` is
the whole route. The server file holds the route alone; the client file calls it through the api type.

- **drizzle**: plain drizzle tables, params typed with drizzle types, return type inferred by drizzle.
- **types**: slim tables written as types, params and return type written with the slim models.
- **builders**: slim builder tables, params and return type written with the slim models.
